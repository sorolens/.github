# Sorolens

Open-source observability tooling for Soroban smart contracts on Stellar.

## What we build

- **[sorolens](https://github.com/sorolens/sorolens)**: dashboard, API, indexer, and CLI for tracking Soroban contracts. Watch events, storage TTL, and invocation health across testnet and mainnet.
